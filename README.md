# Marcador de Lotes Sujos

Ferramenta de apoio à fiscalização para o SisGeoBV (Prefeitura de Boa Vista).
Desenvolvido por Anderson Paulino Cavalcante · Fiscal Tributário · Departamento de Fiscalização.

O arquivo `lotes_sujos.js` é carregado pelo favorito "Lotes sujos" dentro do SisGeoBV.
Não contém senhas, chaves de acesso nem dados de contribuintes; só funciona com login no SisGeoBV.
